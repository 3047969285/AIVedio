# AIVedio

制作 AI 漫剧。技能包在 `漫剧生成skill/`。

| 目录 | 用途 |
| --- | --- |
| `01-短剧漫剧全流程` | 从原著或点子到剧本、分镜、提示词、确认后生产和剪辑 |
| `02-小说到视频与即梦` | 小说拆解、角色与分镜提示词，以及即梦 / Seedream / Seedance 出图出视频 |
| `03-分镜图到Seedance视频提示词` | 分镜板到 Seedance 2.0 视频提示词 |
| `04-AI视频分镜提示词` | 超过单次生成时长的多分镜提示词 |

这些目录来自本地技能合集，各自保留原项目许可。使用前先确认对应模型、声音和音乐的账号与时长限制。
